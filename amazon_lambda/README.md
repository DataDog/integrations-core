# AWS Lambda

## Overview

Monitor AWS Lambda metrics, logs, and traces in Datadog. The Lambda MicroVM Monitoring dashboard provides views of active MicroVM instances, image activity, CPU usage, lifecycle events, logs, and traces.

## Setup

See the [Lambda MicroVM monitoring documentation][1] for setup instructions.

## Data Collected

The dashboard displays MicroVM metrics, logs, and traces available in Datadog. Use the dashboard filters to scope the view by AWS account, region, resource type, image, and environment.
